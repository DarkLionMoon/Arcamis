⚔ Export Contenuti Arcamis

Fetcha tutti i contenuti da Notion/Google e li salva come JSON locale

📦 Export Completo

Fetcha pagine wiki, database, mestieri e documenti. I file JSON vengono scaricati come ZIP.

📄 Export Singolo

Exporta una singola pagina wiki. Incolla l'ID Notion o il route key.

ℹ️ Note

  • L'export usa le API endpoints del sito (/api/notion)
  • Le immagini S3 vengono convertite in riferimenti lazy
  • I file JSON sono pronti per essere caricati nell'admin panel
  • Dopo l'export, incolla i JSON nell'admin panel e salva su GitHub
